# 本番ノートPCからのローカル配信・投影手順

## 配信構成

本番は、資料一式を別のWindowsノートPCへコピーし、そのPCのローカルHTTPサーバーから配信する。社内公開サーバーへの到達、社内LAN、Tailscale、インターネットは静止スライドの表示に不要。ただし39ページのYouTube埋め込み動画の再生にはインターネット接続が必要。画像・台本・CSS・JavaScriptを一式に含める。出典の外部サイトや社内管理ポータルのリンク先は、オフラインでは開けない。

ノートPCの同じEdgeまたはChrome・同じプロファイルで、投影画面と講師画面を開く。プロジェクターはノートPCの拡張ディスプレイとして接続する。別PCやスマートフォンからのページ送り・同期には対応しない。

スライド・台本の内容はサーバー配信と共通。ローカル用に本文を変更しない。

## 事前準備（開発PC）

1. `system/web/public` が本番に使う版であることを確認する。台本を変更した場合は `node system/tools/export-script.cjs` を実行してから梱包する。
2. リポジトリルートで次を実行する。

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File .\system\tools\package-local.ps1
   ```

3. 出力されたZIPとSHA256を記録する。標準出力先は `%TEMP%\kifu-kouza-local`。USBメモリー等でZIPを本番PCへコピーする。ZIPには公開ファイルだけを含め、Git履歴やSSH鍵は含めない。
4. 更新があればZIPを作り直し、本番PCでは新しいフォルダーへ全体を展開する。古いファイルへの部分的な上書きは避ける。確認済みの旧版ZIPも復旧用に保存する。

## 事前準備（本番ノートPC）

1. Python 3とEdgeまたはChromeを事前にインストールする。Pythonは標準ライブラリだけを使い、追加パッケージは不要。PowerShellで `py -3 --version` または `python --version` がPython 3を表示することを確認する。Python本体はZIPに含まれないため、会場に行く前に準備する。
2. ZIPを `C:\Lecture` などのローカルフォルダーへ**すべて展開**する。ZIP内から直接起動しない。`start-local.cmd`、`serve-local.py`、`public` が同じ階層にあることを確認する。
3. 必要ならコピー元とコピー先で `Get-FileHash <ZIPのパス> -Algorithm SHA256` を比較する。
4. `start-local.cmd` をダブルクリックする。ブラウザーで `http://127.0.0.1:8310/` が開く。起動した黒いウィンドウは講義中閉じない。
5. インターネットを切った状態で以下を確認する。実際に使用するノートPC・ブラウザー・プロジェクターでリハーサルする。
   - 全ページの文字・画像が表示され、最後のページまで進める。
   - 「講師ウィンドウを開く」でセリフと次ページが表示される。必要ならポップアップを許可する。
   - 両画面からのページ送りが同期し、講師画面のホイールではセリフだけがスクロールする。
   - タイマーの開始・一時停止・リセットが動く。
   - `http://127.0.0.1:8310/admin.html` から台本2種類を開ける。

## 当日の起動・投影

1. AC電源を接続し、スリープ・通知・自動更新による中断が起きない設定を確認する。
2. プロジェクターを接続し、`Win+P` →「拡張」を選ぶ。「複製」では手元の台本も投影されるため使わない。
3. `start-local.cmd` を起動する。スライドから講師ウィンドウを開く。両画面のURLは同じ `127.0.0.1:8310` に統一する。`localhost` や社内サーバーのURLと混在させない。通常ウィンドウとInPrivateも混在させない。
4. スライドをプロジェクターへ、講師画面を手元へ移動する。投影側で `F` を押して全画面にする。`Esc` で操作バーを戻せる。
5. 投影内容がスライドだけであることを確認して、開始ページへ戻す。タイマーはリセットし、講義開始時に開始する。
6. 終了後はサーバーのウィンドウで `Ctrl+C` を押し、ブラウザーを閉じる。

## 困った場合

- **Pythonがない／Microsoft Storeが開く**：事前にPython 3を導入し、上記のバージョン確認を行う。
- **ポート8310が使用中**：起動済みの講義サーバーがないか確認する。別ポートで起動する場合は展開フォルダーで `start-local.cmd --port 8311` を実行し、両画面を `http://127.0.0.1:8311/` から開き直す。
- **画像が出ない**：ZIPの展開漏れや旧版との混在を確認し、新しいフォルダーへ全展開する。HTMLを直接ダブルクリックする `file://` での運用はしない。
- **画面が同期しない**：同じブラウザー・プロファイル・ホスト・ポートで開き、スライドから講師ウィンドウを開き直す。
- **サーバーを閉じた**：同じ起動ファイルを再実行する。必要なら `http://127.0.0.1:8310/#28` のようにページ番号を指定し、講師画面を開き直す。タイマーは再確認する。
- **最新版で問題が出た**：サーバーを停止し、事前確認済みの旧版を別フォルダーから起動する。

ローカルサーバーは `127.0.0.1` のみで待ち受け、他の端末へ配信しない。管理者権限や受信ファイアウォール規則の追加は不要。

## 39ページの動画を使う場合

動画はYouTube埋め込みで、持ち出しZIPに動画本体は含まない。会場のインターネット接続で、事前に39ページの動画が映像・音声とも再生できることを確認する。HDMI接続時は音声の出力先と音量も確認する。動画は投影画面でクリックして再生する（講師画面のプレビューとは再生同期しない）。自動再生はしない。プレーヤー操作中にページ送りできなくなった場合はプレーヤー外をクリックするか、講師画面から送る。

埋め込み再生が制限される場合は、動画下の「YouTubeで開く」を使う。回線がない場合はYouTubeリンクも再生できないため、動画を省略して次へ進む。オフラインで動画再生が必要な場合は、作成者から利用許可済み動画ファイルを受領して別途対応する。動画の視聴・説明時間は未設定であり、既存91分に追加となる。
