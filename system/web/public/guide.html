講義管理・セリフのダウンロード / スライドを開く / 講師画面を開く / プロジェクト管理トップ

2画面で使う

  1. スライドを開き、「講師ウィンドウを開く」を押します。別ウィンドウが開き、スライド側の操作バーは隠れます。
  2. スライドのウィンドウをプロジェクター側へ移し、講師ウィンドウを手元の画面に置きます。画面配置はOSのディスプレイ設定で「拡張」にします。
  3. スライド側で F キーを押すと全画面表示できます。操作バーを戻すには Esc キーを押します。
  4. 講師側の「送る」「戻る」、左右キーで両画面が同期します。講師側にはセリフ・進行メモ・目安時間・次ページが表示されます。

別ウィンドウを開けない場合は、このサイトのポップアップを許可してください。同じブラウザ・同じサイト内のウィンドウで同期します。別端末や別ブラウザ間の遠隔操作には対応していません。

操作

  • 左右キー / PageUp・PageDown：前後のページへ移動（スライド側はホイールも可）
  • スライド側の Space：次ページ / Home・End：最初・最後
  • スライド側の O：一覧 / N：講師メモ / F：全画面
  • 講師側のホイール：長いセリフや出典をスクロール（ページは送らない）
  • 講師側の「文字 ＋ / −」：セリフの文字サイズ変更
  • 「開始」：経過タイマーの開始・一時停止 / 時間をリセット：00:00へ戻す

講義の時間配分

67ページ、90分。導入・前半45分（坪井）、後半40分（山下）、締め・質疑5分（坪井）。時間は発表・写真の説明・問いかけを含む目安で、自動送りは行いません。セリフは講師用の下書きで、進行メモに沿って実例の説明や対話を補います。
